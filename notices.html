Brain for Mac

Included in the app:

  • Node.jsRuns Brain’s meeting-assistant tooling. Distributed under the Node.js project licenses.
  • llama.cpp and ggmlRun the built-in summary model on your Mac. MIT license.
  • Swift Markdown and Swift cmarkRender the meeting assistant’s answers. Apache 2.0 and BSD licenses.

Downloaded only if you ask Brain for its built-in model:

  • Gemma 4 E4B ITBy Google, quantized by Unsloth, under the Apache 2.0 license. Brain checks the downloaded file against a pinned checksum before using it.

Speech recognition uses Apple’s on-device speech frameworks, which are part of macOS.

Brain for Windows

Included in the app or installed with its speech tools:

  • Local speech runtimesCTranslate2, faster-whisper, Whisper, Sortformer, Sherpa and ONNX Runtime support transcription and speaker separation. Each runtime includes its own license texts and dependency notices.
  • NVIDIA TitaNet largeBrain’s adapted speaker model supports matching enrolled voices. Creative Commons Attribution 4.0 license; attribution and adaptation details appear in the Windows notices.
  • llama.cpp and LLVM OpenMPRun the built-in summary model. MIT and Apache 2.0 licenses.
  • Ical.Net and NodaTimeRead calendar files and links. MIT and Apache 2.0 licenses.
  • Microsoft Windows App SDK, WebView2, and .NETProvide the app’s window, web views, and runtime, under Microsoft’s license terms and their bundled open-source notices.

Downloaded only if you ask Brain for its built-in model:

  • Gemma 4 E4B ITBy Google, quantized by Unsloth, under the Apache 2.0 license. Brain checks the downloaded file against a pinned checksum before using it.
  • Qwen3-4B-Instruct-2507Retained for existing installations. By the Qwen team at Alibaba Cloud, under the Apache 2.0 license.
